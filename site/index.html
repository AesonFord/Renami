First launch

Renami isn't signed with an Apple or Microsoft certificate yet, so your system asks before the first launch. After that, it opens normally.

macOS

Open the .dmg and drag Renami to Applications. The first time you open it, macOS blocks it. Open System Settings, then Privacy & Security, and click Open Anyway. On macOS 14 and earlier, right-click the app, then choose Open, is enough.

Windows

If SmartScreen says it protected your PC, click More info, then Run anyway.

Linux

On Ubuntu 24.04 and later, AppArmor's limit on unprivileged user namespaces can stop the AppImage from starting. Install the .deb instead, or allow the AppImage with an AppArmor profile.
