User guide

Renami renames files in bulk. You add files, write one name pattern, check the live preview, and click Rename. Nothing changes on disk until you do, and a rename can be undone until you quit.

For Renami 0.4.0. Keyboard shortcuts are written for macOS; on Windows and Linux, read ⌘ as Ctrl.

Adding files

Drop files or folders anywhere on the window, or use Add Files… (⌘O) and Add Folder… (⇧⌘O) in the File menu. A folder adds the files directly inside it; turn on Include subfolders in the filters to go deeper. The strip at the top lists each source you added, with a count, and a button to remove it.

You can also start from outside the app: drop files or a folder on Renami's icon in the Dock, choose Renami under Open With in Finder or your file manager, or on Windows right-click a folder in Explorer and pick Rename with Renami. If Renami is already open, the files go to the open window.

Renami reads each file's details as it is added: dates, camera settings, audio tags and so on. The status in the strip says Reading file details… while this runs. You can write the pattern meanwhile; the preview fills in as details arrive.

Filters and folder mode

Click Filters in the strip to narrow what Renami lists from your sources:

  • Include subfolders adds the files in every folder below a dropped folder.
  • File types keeps only the extensions you pick, such as jpg and heic. Files with no extension have their own entry.
  • Name contains keeps files whose name contains the text, ignoring case. Write a regular expression if you like; an invalid one is matched as plain text.
  • Size from and Size to, in megabytes, and a range of modified dates, inclusive.

Folder mode switches what gets renamed: instead of the files, Renami lists the folders directly inside each source, and the pattern names those folders. Subfolder and file-type filters don't apply in folder mode. Folders have no extension, so their whole name is {name}.

Files a filter leaves out are not shown and are never touched.

The name pattern

The pattern at the top of the window is the new name for every file. Plain text is kept as written; anything in braces is a token that Renami fills in from the file:

Hawaii_{date_taken:YYYY-MM-DD}_{seq:3}
IMG_4821.jpg  becomes  Hawaii_2024-07-04_001.jpg

The extension is kept automatically; don't write it in the pattern. The default pattern, {name}, keeps each file's current name, which is the starting point for a find & replace or a case change.

WriteTo get
{token}The token's value, such as {camera_model}.
{date_taken:YYYY-MM-DD}A date in the format you give. YYYY year, MM month, MMM Jan, DD day, ddd Thu, HH hour, hh A 12-hour clock, mm minute, ss second, SSS milliseconds. Other characters are kept as written.
{seq:4}A number padded to that many digits (1 to 10): 0001. Works for {seq}, {track} and {disc}. Without a format, {seq} uses the Digits setting on the Sequence tab.
{artist|Unknown}A fallback, used when the file has no value for the token. Anything after | is the fallback, and it can be empty: {artist|}.
/A folder separator. {date_taken:YYYY}/{name} moves each file into a folder named after its year, creating it if needed. See Move into folders.
{{ and }}A literal brace.

The palette under the pattern inserts the common tokens with a click, grouped as Dates, Number, File, Photo & video and Audio; All tokens… opens a searchable list of every token, with its value for the first file. Click a token already in the pattern to edit it in place: its date format, digits or fallback, or to remove it. A pattern error is shown under the field, with the position, and Rename stays off until it's fixed.

Every token

A token with no value for a file comes out empty and the row is flagged, unless you give it a fallback.

The preview

Every file is a row: a checkbox, the current name, and the new name. The rows update as you type. A flag on a row means it needs a look:

  • A suffix was added, such as _2, because the name was already taken by another file in the batch or on disk. Add {seq} or another token that tells them apart.
  • A token had no value, so part of the name is empty, or the file's metadata couldn't be read. Give the token a fallback, or accept it.
  • An error: the new name is empty, a name or folder name is longer than the file system allows, the full path is longer than Windows allows, the destination can't be written, or a folder would be moved to another drive. Errors block the whole rename until you fix the pattern or leave those files out.

Tick Show only files that need a look above the table to hide the rest. Untick a row to leave that file out of the rename; it stays as it is, and the sequence numbers close up around it. The checkbox in the header ticks or unticks every row shown.

Type a name for one file by double-clicking its new name. Enter keeps it, Esc gives it up. A typed name wins over the pattern for that file; the extension is kept.

See the file by clicking its row: a panel opens with the image, video, audio player, or PDF, and the file's details, with buttons to show it in Finder or Explorer and to open it in its own app. The arrow keys move through the rows, Delete leaves the selected file out and moves on, and the panel can be dragged wider or narrower.

Columns can be dragged to resize. Double-click a column edge to fit it, or right-click the header to reset the widths. The arrow keys resize a column edge that has focus.

The line under the table sums it up: how many files will be renamed, moved, or left alone, and what still stands in the way of renaming.

Sequence

The Sequence tab controls {seq}.

  • Sort by date taken, created, modified or name, ascending or descending. Descending numbers the newest file first. Choose Manual order to set the order yourself: drag rows in the preview, or press Alt with the arrow keys on a row.
  • Start at, Step and Digits: start at 100 in steps of 10 with 4 digits gives 0100, 0110, 0120.
  • Restart the count in each folder, or each day, month or year of the sort date. With a restart each day and a date in the pattern, {date_taken:YYYY-MM-DD}_{seq:3} counts from 001 again every morning.
  • Keep same-name files together gives files that share a name, such as a RAW file and the JPEG shot with it, the same number, so they stay paired after the rename. The preview marks them as paired.

If the pattern doesn't use {seq}, the tab says so, so the settings aren't changed for nothing.

Find & replace

Each rule finds text and replaces it, in order, top to bottom. A rule works on either the current name, before it becomes {name}, or the new name, after the pattern has been applied. Tick Match case for an exact-case match, and Regex to use a regular expression. Regex rules can use $1, $2 and so on for captured groups: find ^(\d+)-(\d+)$ and replace with $2-$1 to swap two numbers. A bad regex is reported under the rule and ignored until fixed.

Leave the pattern at {name} to use Renami purely as a find-and-replace tool.

Case & cleanup

  • Case: keep as is, lowercase, UPPERCASE, Title Case, Sentence case, snake_case, kebab-case or camelCase, applied to the new name.
  • Spaces to underscores, and lowercase extension (.JPG to .jpg).
  • Strip accents turns é into e. ASCII only does that and replaces every other non-ASCII character with _, for names that must travel anywhere.
  • Extension rules map one extension to another: jpeg to jpg, tif to tiff. Leave the "to" side empty to drop the extension. Extensions no rule names keep theirs.

Always on: repeated separators are collapsed, and names are made safe for Windows, so a name that works on your Mac still works when the files are copied to a PC.

Move into folders

By default each file stays in its own folder and only its name changes. Choose One folder and pick a destination to gather every file there. Either way, a / in the pattern makes subfolders: {date_taken:YYYY}/{date_taken:MM}/{name} files photos by year and month, creating the folders as needed. Rows that will move say so in the preview, and undo brings the files back and removes folders it created that are left empty.

File dates

  • Set modified date to date taken and Set created date to date taken change the file's dates on disk to match its metadata, so files sort correctly in Finder or Explorer. Only files with a real date taken are changed; the others keep their dates. Linux doesn't let apps change a file's created date, so that option is off there.
  • Shift date taken by a number of hours and minutes, for a camera whose clock was wrong or set to another time zone. The shift applies wherever the date taken is used: in {date_taken}, in the sort order, and in the dates written to the file.
  • Use a date found in the file name when there is no date taken: a screenshot called Screenshot 2024-07-04 at 10.18.33.png has no metadata, but its name has a date, and Renami uses that.

A file whose name stays the same but whose dates will change is still part of the rename, and the preview says so.

Presets

A preset saves the pattern and every option on the tabs, but not the files. Click Save preset beside the preset list in the strip, name it, and it's there next time you open Renami. Choosing a preset replaces the pattern and options; your file list stays. Presets are kept in presets.json in Renami's application data folder, so you can copy them to another computer.

Importing and exporting names

Import Names… (⌘I) reads a text or CSV file of names and types them into the preview for you. It takes either one new name per line, applied to the rows in preview order, or pairs of current name and new name separated by a tab or a comma, matched to files by their current name. A header line is skipped. This is the way to rename from a spreadsheet: export the preview, edit the new-name column, import it back.

Export Preview… (⇧⌘E) writes the preview as CSV: each file's current name, new name, status, the date used, its folder and full path. Export Last Rename… writes a CSV of every file the last rename changed, from and to, which is a good record to keep before the undo history is gone.

Renaming and undo

Click Rename under the preview (the button says how many files), or press ⌘↩. Just before renaming, Renami checks that no file has changed since the preview was made. If one has, nothing is renamed, the preview is refreshed, and you can look it over and try again. While a long rename runs you see its progress and can cancel; a cancelled rename puts every file already moved back where it was.

When it's done, a notice offers Undo. Undo Last Rename in the File menu (⌥⌘Z on macOS) does the same, until you quit: Renami warns you before quitting while an undo is still possible. Undo skips a file that has changed since the rename, and explains which in a report you can copy.

Renami renames files by moving them, so it never rewrites their contents. A move to another drive is a copy, checked, after which the original is deleted; it takes as long as copying does, the copy gets a new created date, and the preview warns you first. Folders can't be moved to another drive.

The command line

The same engine is available as a command for scripts and servers. It previews by default and changes nothing without --apply; with --journal it writes an undo file you can replay any time, even after other runs. Settings the app can save as a preset can be given to it as JSON. See the command line section of the README.
